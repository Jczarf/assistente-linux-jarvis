# Política de Segurança

## Relato de vulnerabilidades

Se você encontrar uma falha de segurança neste projeto, evite publicar credenciais, dados pessoais, exploits completos ou informações sensíveis em uma issue pública.

Entre em contato com o autor pelo LinkedIn indicado no README, descrevendo o problema de forma suficiente para reprodução sem incluir segredos reais.

## Escopo

A edição pública é um projeto de portfólio e laboratório técnico. Ela não é uma sandbox formal e não deve ser executada com privilégios elevados ou em máquinas contendo dados sensíveis sem uma avaliação adicional.

O shell genérico permanece desativado por padrão. Habilitá-lo altera significativamente o perfil de risco do projeto.

Mais detalhes: [`docs/SEGURANCA.md`](docs/SEGURANCA.md).
