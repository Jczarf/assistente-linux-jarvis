# Contribuindo

Este repositório é mantido principalmente como projeto de portfólio e estudo.

Sugestões técnicas são bem-vindas através de issues ou pull requests, especialmente quando melhoram:

- portabilidade entre distribuições Linux;
- segurança das ferramentas locais;
- testes;
- documentação;
- separação entre orquestração do LLM e efeitos no sistema.

## Regras

1. Nunca inclua chaves, tokens, senhas ou dados pessoais em commits.
2. Novas ferramentas devem ter argumentos explícitos e o menor privilégio possível.
3. Capacidades destrutivas não devem ser ativadas por padrão.
4. Mudanças de comportamento devem incluir testes quando aplicável.
5. Não adicione dependência de um caminho, usuário ou programa específico sem fallback/documentação.

A licença do projeto não concede direito de redistribuição automática; contribuições aceitas passam a integrar o projeto sob os mesmos termos do repositório.
