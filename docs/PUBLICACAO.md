# Checklist de publicação

Antes de alterar a visibilidade do repositório para público:

- [x] projeto separado do monorepo privado;
- [x] histórico novo, sem copiar commits antigos;
- [x] segredos movidos para variáveis de ambiente;
- [x] `.env` e formatos comuns de chave ignorados;
- [x] caminhos e programas específicos do computador original removidos do núcleo público;
- [x] memória persistente desativada por padrão;
- [x] shell genérico desativado por padrão;
- [x] documentação de limitações de segurança;
- [x] licença de portfólio adicionada;
- [x] imagens e diagramas locais adicionados;
- [x] testes automatizados adicionados;
- [x] workflow de CI adicionado;
- [ ] confirmar que o workflow de CI está verde;
- [ ] revisar manualmente a aba de commits e arquivos;
- [ ] ativar recursos de secret scanning disponíveis na conta/repositório;
- [ ] definir descrição e tópicos do repositório no GitHub;
- [ ] tornar o repositório público somente após os itens acima.

## Descrição sugerida
